## Writing Your Grant Proposals

### Template: Problem Statement (150 words)

```
Current State:
- [Statistic 1]: [Impact 1]
- [Statistic 2]: [Impact 2]
- [Gap 3]: [Why it matters]

Why It Matters:
- [Consequence 1]
- [Consequence 2]

Examples:
  1. 1.7B unbanked people (Statistic)
     → Can't access credit (Impact)
  2. DeFi lending requires 150% collateral (Gap)
     → Excludes 99% of global population (Why it matters)
  3. Identity is centralized (Barrier)
     → Privacy violations + censorship risk (Consequence)
```

### Template: Solution (200 words)

```
What We're Building:

[Layer 1 - Technical Foundation]
- What: [Component 1]
- How: [Mechanism]
- Why: [Benefit]

[Layer 2 - Integration]
- What: [Component 2]
- How: [Process]
- Why: [Benefit]

[Layer 3 - Outcome]
- What: [Component 3]
- How: [Result]
- Why: [Impact]

Example:
  Layer 1 - Identity
    What: On-chain identity registry
    How: ERC-725-style contracts
    Why: Users own their identity

  Layer 2 - Attestations
    What: Privacy-preserving attestations
    How: EIP-712 typed data signing
    Why: Tamper-proof credentials

  Layer 3 - Lending
    What: Under-collateralized loans
    How: Credit scoring oracle
    Why: 75% less collateral required
```

### Template: Why It's Innovative (100 words)

```
Compared to Current Solutions:

Traditional Finance:
- Requires: [Barrier]
- Excludes: [Who]
- Problem: [Pain point]

Current DeFi:
- Requires: [Barrier]
- Excludes: [Who]
- Problem: [Pain point]

RealMint:
- Enables: [Solution]
- Includes: [Who]
- Benefit: [Outcome]
```

## Important Notes

### ⚠️ Critical Success Factors

1. **Speed:** Be first to apply (beat the rush)
2. **Clarity:** Everyone should understand RealMint in <2 minutes
3. **Proof:** Show working code (11 tests passing, Sepolia live)
4. **Community:** Build audience before/during applications
5. **Authenticity:** Real project, not hype (we have substance)

### ❌ Common Mistakes to Avoid

- Don't wait for "perfect" before applying (good enough = ship)
- Don't oversell (claims will be scrutinized)
- Don't apply to incompatible programs (waste of time)
- Don't disappear after getting funded (report progress!)
- Don't use grant $ for personal spending (fraud risk)

### ✅ Confidence Builders

- You have production-ready code (11/11 tests)
- You have real problem (1.7B unbanked)
- You have real solution (identity + lending)
- You have real timeline (Month 1-2 mainnet)
- You have open source commitment (MIT license)
