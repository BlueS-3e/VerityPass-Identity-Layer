## FAQs for Grantors

**Q: Why should Ethereum Foundation fund this vs. other projects?**

A: Identity and attestations are infrastructure that benefit the entire ecosystem. Unlike a specific dApp, our code is a reusable standard that Uniswap, Compound, Aave can all integrate. It's multiplicative investment.

**Q: What's your competitive advantage?**

A: Privacy-first architecture + Plaid integration + under-collateralization focus. No other project combines all three.

**Q: How do you prevent issuer fraud?**

A: Issuer reputation system on-chain. Only attestations from reputable issuers are accepted. Slashing for fraudulent issuers.

**Q: What's your token economics?**

A: No token yet. Governance token future (DAO phase). No trading / no speculation. Pure governance.

**Q: Will this work in regulated jurisdictions?**

A: We're building compliance framework from day 1. Off-chain PII + on-chain audit trail makes it audit-friendly. Legal review pre-launch.

**Q: Can I use this with my hardware wallet?**

A: Yes. We support EIP-6963 (Ledger, Trezor, MetaMask all work).
